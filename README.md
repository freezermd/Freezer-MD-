## 🥶 About

**Freezer-MD** is a modular WhatsApp automation bot designed for
groups, media, administration, entertainment, automation and utility
commands.

Built around a plugin-based architecture, Freezer-MD makes it easy to
add, remove and update commands without rebuilding the entire bot.

> **Freeze the limits. Build your own. 🥶👊**
